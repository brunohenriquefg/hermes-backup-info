# Hermes Backup — public information

Static public information, privacy policy and usage conditions for an independently administered, restricted-use Google Drive OAuth client.

- `index.html`: purpose and access scope.
- `privacy.html`: data handling and revocation.
- `terms.html`: operating conditions.
- `.nojekyll`: serve plain static HTML, without a custom build workflow.

No credentials, backup files, operational configuration or company documents belong in this repository. No analytics, scripts or third-party fonts are included.

Publishing these pages does not establish that the backup mechanism is configured or tested. This is not an official Google, GitHub or Nous Research product.
