Hermes Backup

Cliente OAuth dedicado à cópia de segurança de uma instalação do Hermes Agent no Google Drive do seu administrador.

Finalidade

A integração usa rclone para comunicar-se com a API do Google Drive. O mecanismo de backup é destinado a proteger arquivos de configuração e estado da instalação, com criptografia local antes do envio ao armazenamento remoto.

Acesso solicitado

É solicitado apenas o escopo drive.file: acesso aos arquivos específicos criados ou autorizados para este aplicativo. Esta conexão não solicita acesso geral aos documentos existentes, ao Gmail, à agenda ou aos contatos.

Uso restrito ao administrador

Não há cadastro público, serviço de hospedagem de backups para terceiros ou execução de agentes neste site. A presença destas páginas não concede acesso a nenhuma conta ou arquivo. Cada acesso ao Drive depende do consentimento do titular.

Responsável e contato

O cliente é administrado pelo titular do projeto OAuth. Para assuntos relacionados a esta configuração, utilize o endereço de suporte apresentado na tela de consentimento do Google ou o repositório público de documentação. Não publique arquivos de backup, senhas, tokens ou dados pessoais em issues.

Leia a política de privacidade e as condições de uso.

Configuração independente. Este site não representa um produto oficial do Google, do GitHub ou da Nous Research. Não contém credenciais nem arquivos de backup.
